CPU and assembly simulator

“A program runs” is a black box until you watch each instruction move a value, set a flag, take a branch. This is a tiny, honest CPU: write assembly, then step through it and watch the registers, flags, stack and memory change under your hands.

  • A small, documented instruction set
  • Step one instruction at a time
  • Live registers, flags, stack, memory
  • Example programs to load
  • A real assembler — no eval

How a computer actually runs

The whole machine, small

Eight registers, a program counter, a stack pointer, three flags, and a couple of dozen instructions — MOV, ADD, CMP, jumps, LOAD/STORE, CALL/RET. That is enough to write real programs and small enough to hold in your head, which is exactly why it teaches.

Step and watch

Assemble a program, then step one instruction at a time. The current line highlights, and every register, flag, stack slot and memory cell that changed flashes. Loops, conditionals and function calls stop being abstract when you watch the PC jump and the stack grow.

A real assembler, not eval

The source is parsed by a proper two-pass assembler — labels resolved, operands decoded — never by eval. That is a correctness and a security decision: the site’s strict CSP forbids eval, and a toy that secretly used it would be a bad example on a security site.

Load an example

Fibonacci, factorial, summing an array, a bubble sort — load one and step through it to see how a familiar algorithm looks at the level of registers and jumps.

Questions people ask

Do I need to know assembly already?
No. The instruction set is small and documented on the page, and the example programs show the patterns. Stepping through them is a good way to learn what assembly is.
Is this a real CPU architecture?
It is a small, clean teaching instruction set rather than x86 or ARM - the concepts (registers, flags, jumps, a stack, load/store) are exactly the same, without the decades of real-world complication.
How does it run the code without eval?
A two-pass assembler parses your source into an internal representation, and an interpreter executes that. No eval or new Function is used anywhere, which also satisfies the site's strict Content-Security-Policy.
Can I watch memory and the stack?
Yes. Registers, flags, a memory grid and the stack are all shown live, and cells that change on a step are highlighted.
Does it run on my machine?
Entirely in your browser. Nothing is uploaded.
