CVSS v3.1 calculator

The formula is published and it is entirely arithmetic, so a calculator for it has no business being a web service. Each metric shows what it contributed, and the result comes with the caveat that matters.

  • Official CVSS v3.1 base formula
  • Every metric explained in plain English
  • Per-metric contribution shown
  • Paste a vector string to load it
  • Nothing uploaded

Before you start

This tool runs entirely inside your browser. Nothing you paste or drop here is uploaded, logged or stored — which for security work is the whole point, not a footnote.

What it does not do

  • No uploads — there is no server to upload to
  • No account, no history, nothing saved
  • Base score only — temporal and environmental metrics are not included
  • No CVE database lookups

Why that matters here

  • Evidence files stay on your machine
  • A token or key you paste is never transmitted
  • Nothing you paste ever appears in your Network tab
  • Works with no internet once the page is cached
  • Free, permanently

Using the number well

        

        

          

            
What CVSS measures

            
A vulnerability in the abstract: how hard it is to exploit, and how bad it is when exploited. It knows nothing about whether the affected system is internet-facing, whether the data on it matters, whether a patch exists, or whether anyone is exploiting it today.

          

          

            
Which is why 9.8 is not a priority

            
A 9.8 on an isolated internal host can be far less urgent than a 6.1 on your public login page. CVSS is for comparing severities on a common scale. Priority needs exposure, asset value and threat intelligence on top — which is what EPSS and KEV catalogues add.

          

          

            
Scope is the metric people get wrong

            
Changed scope applies a 1.08 multiplier and raises the privileges-required weights, so it moves the score more than anything else. It means the impact escapes into a component with a different security authority — a sandbox escape, a hypervisor break — not merely that something else is also affected.

          

          

            
Base, temporal, environmental

            
This calculates the base score, which is what CVEs publish and what almost everyone means by “the CVSS score”. Temporal adjusts for exploit maturity and remediation; environmental adjusts for your specific deployment. Both start from this number.

          

        

      


      

        

          
Questions people ask

        

          

            Is this the official CVSS formula?
            
Yes. It implements the CVSS v3.1 base score equations published by FIRST, including the specification Roundup function, which is why the results match the official calculator exactly rather than being off by a decimal.

          

          

            What is the difference between CVSS 3.0 and 3.1?
            
The metrics are identical. 3.1 clarified definitions and fixed the rounding function, which is where 3.0 implementations occasionally disagreed by 0.1.

          

          

            What about CVSS v4.0?
            
It exists. FIRST published v4.0 in 2023, and it is a restructuring rather than a tweak: it adds Attack Requirements alongside Attack Complexity, splits the single impact triad into Vulnerable System impact (VC, VI, VA) and Subsequent System impact (SC, SI, SA), and reorganises the optional metrics into a Threat group that replaces Temporal and a reworked Environmental group. This calculator implements v3.1, which is still the version most advisories and CVE records carry, so paste v3.1 vectors here. A v4.0 string shares only some of its metric names with v3.1 and will not score correctly.

          

          

            Should I patch everything above 7.0 first?
            
Not necessarily. CVSS does not know your environment. A high-scoring flaw in software you do not expose can wait behind a medium-scoring flaw on your perimeter. Use CVSS to compare, and exposure and exploitation data to prioritise.

          

          

            Can I load an existing vector string?
            
Yes. Paste a CVSS:3.1/... string into the field and press Load vector; the dropdowns update and the score recalculates.

          

          

            Does this look up CVEs?
            
No. It makes no network requests. Enter the metrics yourself, or paste the vector string from an advisory.
