A real DOS prompt, running in your browser

FreeDOS booted on an emulated 486, inside your tab. A genuine A:\> prompt with DIR, COPY, TYPE, EDIT and batch files — the command language Windows’ own prompt grew out of. It runs on your machine, it has no network, and every boot starts from a clean disk.

  • Genuine FreeDOS
  • ~720 KB once, then cached
  • No network, fully sealed
  • Fresh disk every boot

Before you start

This boots a real but deliberately minimal DOS machine inside your browser. Please read what it is and is not, then choose whether to continue.

What is not supported

  • This is FreeDOS, not Windows — no PowerShell, no GUI
  • No internet, and no installing anything
  • You cannot load files from your own computer
  • Nothing is saved — every boot starts fresh
  • Not a route for running your old DOS games

What you get

  • A real DOS prompt, file system and batch processor
  • Everything runs on your CPU, in your RAM
  • Capped at 32 MB, sealed off from your computer
  • Safe to break in any way you like
  • Free, no account, no limits

Things to try

          
Click the screen first so the keyboard goes to the machine. ^Z means
          Ctrl + Z then Enter.

        

        

          

            
Look around the disk

            
The classic four. DIR /W gives the wide listing, DIR /P pauses per screen.

            
DIR
DIR /W
VER
MEM

          

          

            
Make a file and read it back

            
COPY CON writes straight from the keyboard — finish with Ctrl+Z then Enter.

            
COPY CON HELLO.TXT
Hello from FreeDOS
^Z
TYPE HELLO.TXT

          

          

            
Write a batch file

            
Batch files are the DOS shell script, and FOR loops work as they always did.

            
COPY CON LOOP.BAT
@ECHO OFF
FOR %%A IN (1 2 3 4 5) DO ECHO Line %%A
^Z
LOOP.BAT

          

          

            
Directories and navigation

            
MD, CD and RD behave exactly as you remember.

            
MD WORK
CD WORK
COPY CON NOTE.TXT
some text
^Z
DIR
CD ..
RD WORK /S

          

        

      


      

        

          
The honest version

          
Why this is DOS and not Windows

        

        

          

            
Windows cannot be offered this way

            

              Windows is licensed software that cannot be redistributed, and a modern install is
              several gigabytes before it boots. No website can hand you a real Windows machine,
              whatever it claims. ReactOS, the open-source Windows-compatible system, does run
              under this emulator — but it is over 500 MB and lands in a desktop, not a prompt.
            

          

          

            
What FreeDOS actually gives you

            

              The command language people mean when they say “cmd” is DOS’s, and
              FreeDOS implements it faithfully in 720 KB. DIR, COPY, TYPE, batch files, drive
              letters, 8.3 filenames — all real. The disk also carries VIM, the NASM
              assembler, DEBUG and a few games, so there is more here than the bare commands. If
              you are learning where the Windows prompt came from, or want somewhere safe to poke
              at a command line, this is the genuine thing rather than a mock-up.
            

          

        

      


      

        

          
Questions people ask

        

          

            Is this Windows, or the Windows command prompt?
            
Neither, and it is worth being straight about that. Windows cannot be redistributed and is gigabytes in size, so no website can legitimately offer it. This is FreeDOS — a real, freely licensed operating system that is command-compatible with MS-DOS, which is the system cmd.exe descends from. If you want DIR, CD, COPY and batch files, this is the genuine article. If you need PowerShell or a Windows GUI, nothing in a browser can give you that.

          

          

            Is it a real operating system or a simulation?
            
Real. v86 emulates a 32-bit x86 processor in WebAssembly and FreeDOS boots on it from an emulated floppy, exactly as it would on 1990s hardware. The file system, the command interpreter and the batch processor are FreeDOS's own.

          

          

            Which commands work?
            
The DOS set: DIR, CD, MD, RD, COPY, DEL, REN, TYPE, MORE, CLS, DATE, TIME, VER, MEM, ATTRIB, FIND, SORT, XCOPY, EDIT and FDISK, plus batch files with ECHO, SET, IF, GOTO and FOR. This particular disk also carries VIM, the NASM assembler, DEBUG, and the games INVADERS, SNAKE and TETRIS. Type HELP for what the system itself reports, or DIR to see everything on the disk.

          

          

            Can I run old DOS games or programs?
            
Not from here — there is no way to load a file from your computer into the emulated floppy, and the disk is read-only. For running your own DOS software, a local emulator such as DOSBox is the right tool.

          

          

            Does it have internet access?
            
No. No network device is attached, so nothing inside can reach anything outside. That is deliberate.

          

          

            Do my files survive a reload?
            
No. The disk image is read-only and memory is discarded when the page unloads, so every boot gives you an identical machine. Files you create with EDIT live only until you leave.

          

          

            Does any of this touch a server?
            
Only to download the 720 KB disk image the first time. After that it is cached and the whole machine runs on your own processor. Nothing you type is transmitted anywhere.
