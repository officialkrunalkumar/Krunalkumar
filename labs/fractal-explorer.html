Fractal explorer

The Mandelbrot set has infinite detail: zoom in anywhere and there is always more. Rendering it on the GPU makes that zoom smooth, and hovering the Mandelbrot to pick a Julia set is the classic, quietly delightful interaction.

Infinite detail

A picture from an equation

The whole Mandelbrot set comes from one line: repeatedly square a complex number and add the starting point, and colour by how fast it runs away. That such simplicity produces endless intricate structure is the reason people have stared at it for forty years.

Why the GPU

Every pixel runs the same iteration independently, which is exactly what a GPU is built for. Doing it in a fragment shader is what makes the zoom smooth instead of a slideshow — the same reason the shader playground and this share an engine.

Mandelbrot and Julia

Each point of the Mandelbrot set corresponds to a whole Julia set. Hover over the Mandelbrot and the Julia view updates to that point, so you can sweep across and watch the Julia set transform — connected here, dust there.

An honest limit

Single-precision floating point on the GPU runs out of resolution after a deep zoom, and the image starts to pixelate. The tool tells you rather than pretending — going deeper needs double precision, which browsers do not expose on the GPU.

Questions people ask

How do I zoom and pan?
Scroll or click to zoom toward the cursor, and drag to pan. The Reset button returns to the full view.
What is the Julia set connection?
Every point in the complex plane defines a Julia set, and the Mandelbrot set is a map of which ones are connected. Hover over the Mandelbrot to use that point as the Julia constant and watch the Julia set change.
Why does it pixelate when I zoom far in?
The GPU computes with single-precision floats, which run out of significant digits after a deep zoom. That is a hardware limit, not a bug - the tool says when you have reached it.
Does it need a powerful computer?
A modern browser with WebGL is enough. It renders on your GPU, so a decent graphics chip makes deep zooms smoother, but it works on integrated graphics too.
Is anything uploaded?
No. It all runs on your GPU in your browser.
