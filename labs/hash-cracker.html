Live password hash cracker

“Your password is cracked in seconds” is abstract until you watch it happen. Type a password, pick a hash, and this cracks it live — guesses per second ticking up — then shows you how long a genuinely strong one would have taken instead.

  • Live guesses-per-second counter
  • Wordlist then brute force
  • MD5, SHA-1, SHA-256
  • Runs in a Web Worker — page stays smooth
  • The number for a strong password too

Before you start

This runs entirely inside your browser — the animation, the maths, all of it on your own machine. Nothing is uploaded and there is no server.

Good to know

  • Everything runs on your device
  • Heavy work runs off the main thread where it can
  • Nothing is uploaded or stored

Why it is here

  • Seeing it beats reading about it
  • Works offline once the page is cached
  • Free, permanently

What the number teaches

        

        

          

            
Weak passwords fall instantly

            
A common password is not brute-forced at all — it is the first thing on the wordlist, matched before the counter has really started. Watching password1 fall in the first few milliseconds is a more convincing argument than any lecture.

          

          

            
Strong passwords never fall

            
The tool also projects, at the same guess rate, how long a genuinely random password of the same length would take. The gap between “instant” and “longer than the age of the universe” is the whole lesson: length and randomness, not complexity theatre.

          

          

            
Why it runs in a worker

            
A cracking loop that ran on the main thread would freeze the page and make the Stop button useless. This runs in a Web Worker so the counter animates smoothly and Stop halts it instantly — the same reason real tools are multi-threaded.

          

          

            
It only cracks what you type

            
Nothing is uploaded and no real hashes are involved unless you provide them. You type a password, it hashes it locally, then races to reverse it. It is a demonstration, in your own tab.

          

        

      


      

        

          
Questions people ask

        

          

            Is anything uploaded?
            
No. The password you type is hashed and cracked entirely in your browser, in a Web Worker. There is no server and no network request.

          

          

            Why does my strong password never crack?
            
Because brute force scales exponentially with length and character set. That is the point - the tool shows the projected time for a strong password so you can see it is effectively never, at any realistic guess rate.

          

          

            Which hashes can it crack?
            
MD5, SHA-1 and SHA-256 - all fast hashes. Real password storage uses deliberately slow hashes (bcrypt, Argon2) precisely so this kind of guessing is millions of times slower.

          

          

            How fast is it?
            
Millions of guesses per second in a modern browser - fast enough to make the lesson vivid, and slow compared to a GPU cracking rig, which does billions. Either way, a weak password falls instantly and a strong one never does.

          

          

            Does the Stop button really stop it?
            
Yes. It terminates the worker immediately, which is why the cracking runs off the main thread in the first place.
