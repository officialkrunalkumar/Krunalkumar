Online compilers that run on your machine, not ours

Eleven languages, three real machines and a couple of other tools, all executing inside your own browser tab. There is no server compiling your code, which means no queue, no account, no usage cap — and no copy of your work anywhere but your own computer. Free, and staying that way.

  • Nothing is uploaded
  • No sign-up
  • Works offline once cached
  • Free forever

How this works, and why it is different

Everything is local

Each language ships as a WebAssembly build of its real interpreter. When you press Run, that interpreter is handed your code inside a Web Worker in your own tab. Your processor does the work and your RAM holds the result. There is no compile server behind this page, so there is nothing for anyone to read, log or leak.

What that costs you

Honesty matters more than a feature list here: because there is no server, there is also no package manager, no network access from your code, and no access to files on your computer. If you need pip install or npm i, this is not the right tool. If you want to run a program and see what it prints, it is.

Runaway programs are safe

Infinite loops and runaway allocations are contained by design. Your code runs in a Worker isolated from the page, so the tab never freezes and the Stop button always works. A watchdog warns you when a program runs unusually long or allocates memory unusually fast, and stops it outright at sixty seconds.

It works on a plane

Once a language’s runtime has been downloaded once, your browser keeps it. From then on the playground works with no internet connection at all — something no server-backed online compiler can offer, at any price.

Questions people ask

Is this really free?
Yes, permanently. There is no server doing the work, so there is no cost to pass on. No account, no trial, no execution limits.
Does my code get uploaded?
No. Every language here runs inside your own browser using your CPU and RAM. Your code is never transmitted, and there is no server that could receive it. You can open your browser's Network tab and watch: the only requests are for the runtime files themselves.
Can I install libraries or packages?
No. pip, npm, LuaRocks and every other package manager need a network connection and a registry, neither of which exists here. Standard libraries only.
Why is the first run slower than the rest?
Most languages need a runtime downloaded once — between 420 KB and 58 MB depending on the language. Your browser caches it, so every run after that starts immediately, and the playground then works with no internet connection at all.
What happens if I write an infinite loop?
Your program runs in a Web Worker, isolated from the page, so the tab stays responsive. A warning with a Cancel button appears after a few seconds, and anything still running at sixty seconds is stopped automatically.
Does this work on a phone?
Yes, though the editor is more comfortable on a larger screen. The lighter languages — JavaScript, Lua and SQL — are the best fit for a phone.
Can I use it offline?
Yes. Once a language's runtime is cached, that playground keeps working without a connection.
