Password strength checker and generator

Most strength meters score the shape of a password — a capital, a digit, a symbol, tick, “Strong”. That is why P@ssw0rd1 passes and is in every wordlist ever assembled. This measures entropy, then subtracts for the patterns crackers already try first.

  • Real entropy, not a shape score
  • Crack time against four hash types
  • Dictionary, keyboard and date detection
  • Generator uses crypto.getRandomValues
  • Never transmitted

Before you start

This tool runs entirely inside your browser. Nothing you paste or drop here is uploaded, logged or stored — which for security work is the whole point, not a footnote.

What it does not do

  • No uploads — there is no server to upload to
  • No account, no history, nothing saved
  • No password is stored, logged or transmitted
  • No check against any breach database

Why that matters here

  • Evidence files stay on your machine
  • A token or key you paste is never transmitted
  • Nothing you paste ever appears in your Network tab
  • Works with no internet once the page is cached
  • Free, permanently

What actually makes a password strong

        

        

          

            
Length beats complexity

            
Every character you add multiplies the search space. Substituting @ for a does not — cracking rule sets expand those automatically, which is why a leetspeak password scores barely better than the word it came from. Four random words beat a short string of symbols and are far easier to type.

          

          

            
Why the hash matters more than the password

            
The same password survives seconds against unsalted MD5 and centuries against Argon2id. If you build systems, the algorithm you choose does more for your users than any complexity rule you impose on them.

          

          

            
What the numbers assume

            
The estimates assume an attacker who has stolen the hash and can guess at full speed offline. That is the scenario that matters, because it is what happens after a database leak. Online guessing against a live login is far slower and usually rate-limited.

          

          

            
The honest advice

            
Use a password manager, let it generate everything, and remember one long passphrase for the manager itself. Then none of the above is your problem. Turn on two-factor authentication wherever it is offered, because it survives the password being wrong.

          

        

      


      

        

          
Questions people ask

        

          

            Is my password sent anywhere?
            
No. It is analysed by JavaScript in your browser as you type. There is no server, no logging and no network request. A password strength checker with a server behind it is a password collection service with a helpful interface.

          

          

            Does it check whether my password was in a data breach?
            
No, deliberately. Every breach-check service needs to receive something derived from your password. Doing that well requires k-anonymity and a network call, and this page makes no network calls at all. Use Have I Been Pwned separately if you want that check.

          

          

            Why does my password score lower than on other sites?
            
Because most meters score composition - did you include a capital and a symbol - rather than entropy. This one subtracts for dictionary words, keyboard runs, dates and the common Capital-word-digits-symbol shape, because attackers try all of those first.

          

          

            Is the generator actually random?
            
It uses crypto.getRandomValues, the browser cryptographic random source. It does not use Math.random, which is predictable and must never pick a password.

          

          

            How long should a password be?
            
For something protecting real value, 16 characters random or five random words. For your password manager master password, longer, and never reused anywhere.
