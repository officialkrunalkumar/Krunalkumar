Online Perl compiler

Real Perl 5, compiled to WebAssembly. The regular expression engine, the hash and list idioms, references and the standard library all behave exactly as they do locally, because this is the genuine interpreter rather than a subset of it.

  • Real Perl 5
  • ~16 MB once, then cached
  • Full regex engine
  • Nothing leaves your device

Before you start

This playground runs entirely inside your browser. Please read what it can and cannot do, then choose whether to continue.

What is not supported

  • Installing libraries or packages of any kind
  • Network access from your program
  • Reading or writing files on your computer
  • Long-running, timing-sensitive or benchmark work
  • Anything beyond the standard library

What you get

  • Your code runs on your machine, in your RAM
  • Nothing is uploaded, logged or stored by us
  • No account, no queue, no execution limits
  • Works offline once the runtime is cached
  • Free, permanently

How to run Perl online

  1. Accept the short notice, then replace the starter program with your own Perl.
  2. print, printf and say all go to the terminal pane.
  3. Press Run, or Ctrl + Enter.
  4. The first run downloads the interpreter (~16 MB); after that it starts in a moment.
  5. use strict; use warnings; is a good habit and works here as normal.

What this Perl playground supports

The interpreter is real, so the language and its core modules are complete. What is missing is CPAN and the world outside the tab.

Works here

  • The full regular expression engine — named captures, lookaround, /x, /g, tr///
  • Hashes, arrays, slices, references and nested data structures
  • sort with custom comparators, grep, map
  • Heredocs, sprintf, string functions and local
  • Core modules such as List::Util, Data::Dumper, POSIX

Does not work here

  • CPAN — no cpan, no cpanm, no third-party modules
  • Network access, LWP and sockets
  • Reading or writing files on your computer
  • system, backticks and fork
  • Reading from an interactive STDIN

Perl examples to try

Each was executed against this exact build before publishing.

Regular expressions

The reason people still reach for Perl. Named captures and all.

my $log = <<'END';
2026-08-18 10:22:01 ERROR disk full on /dev/sda1
2026-08-18 10:22:05 WARN  memory at 91%
2026-08-18 10:23:11 ERROR timeout talking to db
END

while ($log =~ /^(?<date>\S+)\s+(?<time>\S+)\s+(?<level>\w+)\s+(?<msg>.+)$/gm) {
    next unless $+{level} eq 'ERROR';
    printf "%s  %s\n", $+{time}, $+{msg};
}

Hashes and sorting

Perl's hash and sort idioms, which read oddly until they suddenly don't.

my %stock = (apples => 12, pears => 3, plums => 27, figs => 8);

for my $fruit (sort { $stock{$b} <=> $stock{$a} } keys %stock) {
    printf "%-8s %3d\n", $fruit, $stock{$fruit};
}

my @low = grep { $stock{$_} < 10 } sort keys %stock;
print "\nrestock: ", join(', ', @low), "\n";

Text munging with split and join

The one-liner shape Perl was built for.

my @rows = (
    'asha,engineering,92000',
    'ben,engineering,78000',
    'chitra,design,71000',
);

my %total;
for my $row (@rows) {
    my ($name, $dept, $pay) = split /,/, $row;
    $total{$dept} += $pay;
}

printf "%-14s %d\n", $_, $total{$_} for sort keys %total;

References and nested data

Arrays of hashes, the way real Perl scripts hold structured data.

my @people = (
    { name => 'Asha',   langs => ['perl', 'python'] },
    { name => 'Ben',    langs => ['c'] },
);

for my $p (@people) {
    printf "%-6s knows %s\n", $p->{name}, join(' and ', @{ $p->{langs} });
}

Questions people ask

Is this real Perl?
Yes — Perl 5 compiled to WebAssembly through the WebPerl project. The regex engine in particular is the genuine one, which is the part most worth having.
Can I install CPAN modules?
No. CPAN needs a network and a toolchain, neither of which exists here. The core modules that ship with Perl are available.
Why is the first run slow?
Perl and its library come to about 16 MB, downloaded once and then cached by your browser.
Can I read from STDIN?
Not currently — the program runs with no interactive input, so put your data in the script itself. The examples above all do.
Is my Perl code private?
Entirely. It runs in your browser and is never transmitted anywhere.

Something not working?

Tell me and I will fix it

These playgrounds run a lot of machinery inside your browser, and browsers differ. If a program that should run does not, if the output looks wrong, or if anything is odd on your phone — I would genuinely like to know. Feature requests are welcome too.
