Online PHP compiler

Real PHP 8.4, compiled to WebAssembly and running in your tab. Enums, match, readonly properties, constructor promotion and the enormous array library are all genuinely here, because this is the actual PHP interpreter rather than a subset of it.

  • Real PHP 8.4
  • ~14 MB once, then cached
  • Enums, match, readonly props
  • Nothing leaves your device

Before you start

This playground runs entirely inside your browser. Please read what it can and cannot do, then choose whether to continue.

What is not supported

  • Installing libraries or packages of any kind
  • Network access from your program
  • Reading or writing files on your computer
  • Long-running, timing-sensitive or benchmark work
  • Anything beyond the standard library

What you get

  • Your code runs on your machine, in your RAM
  • Nothing is uploaded, logged or stored by us
  • No account, no queue, no execution limits
  • Works offline once the runtime is cached
  • Free, permanently

How to run PHP online

  1. Accept the short notice, then write your PHP in the editor.
  2. The opening <?php tag is optional — it is added for you if you leave it out.
  3. Press Run, or Ctrl + Enter.
  4. Anything echoed or printed appears in the terminal pane, including warnings and fatal errors with their usual PHP wording.
  5. The first run downloads the interpreter (~14 MB); after that it is quick.

What this PHP playground supports

The interpreter is complete, so the language and its huge standard library are all present. What is absent is the web server around it.

Works here

  • PHP 8 syntax: enums, match, readonly properties, promotion, named arguments, nullsafe operators
  • The array library — array_map, usort, array_column, array_reduce and the rest
  • Strings, regular expressions, DateTime, json_encode
  • Classes, interfaces, traits, abstract classes and exceptions
  • Closures, generators and references

Does not work here

  • Composer and any third-party package
  • Superglobals that need a request: $_GET, $_POST, $_SESSION, $_COOKIE
  • Databases — no MySQL, no PDO connection to anything
  • file_get_contents on a URL, cURL, sockets
  • Reading or writing files on your computer

Arrays and array functions

PHP's array library is its best feature; here is a slice of it.

<?php
$sales = [
    ['region' => 'north', 'amount' => 120],
    ['region' => 'south', 'amount' => 80],
    ['region' => 'north', 'amount' => 45],
];

$byRegion = [];
foreach ($sales as $s) {
    $byRegion[$s['region']] = ($byRegion[$s['region']] ?? 0) + $s['amount'];
}

arsort($byRegion);
foreach ($byRegion as $region => $total) {
    printf("%-8s %4d%s", $region, $total, PHP_EOL);
}

echo 'total ', array_sum($byRegion), PHP_EOL;

Classes, interfaces and enums

Modern PHP 8 — typed properties, enums, match, constructor promotion.

<?php
enum Grade: string {
    case A = 'excellent';
    case B = 'good';
    case C = 'passing';
}

class Student {
    public function __construct(
        public readonly string $name,
        public readonly int $marks,
    ) {}

    public function grade(): Grade {
        return match (true) {
            $this->marks >= 90 => Grade::A,
            $this->marks >= 75 => Grade::B,
            default            => Grade::C,
        };
    }
}

foreach ([new Student('Asha', 91), new Student('Ben', 78)] as $s) {
    printf("%-6s %3d  %s%s", $s->name, $s->marks, $s->grade()->value, PHP_EOL);
}

String and date handling

The standard library people reach for every day.

<?php
$text = '  The Quick Brown Fox  ';

echo strtolower(trim($text)), PHP_EOL;
echo str_word_count($text), ' words', PHP_EOL;
echo implode('-', array_map('strrev', explode(' ', trim($text)))), PHP_EOL;

$d = new DateTime('2026-08-18');
echo $d->format('l, j F Y'), PHP_EOL;
echo $d->modify('+30 days')->format('Y-m-d'), PHP_EOL;

Questions people ask

Is this really PHP 8?
Yes — PHP 8.4, compiled to WebAssembly. Enums, match expressions and readonly properties all work, which is the quickest way to confirm it for yourself.
Can I use Composer packages or Laravel?
No. Composer needs a network and a package repository, and frameworks additionally need a web server and usually a database. This runs single PHP scripts.
Do $_GET and $_POST work?
No. Those are populated by a web server handling a request; there is no request and no server here. Put your data in the script.
Can I connect to MySQL?
No. There is no network access at all. For databases, the SQL and PostgreSQL playgrounds run real engines locally instead.

No — it is added automatically if your script does not start with one. Including it yourself is fine too.
