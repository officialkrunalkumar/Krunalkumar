QR code generator and inspector

A QR code is a link you cannot hover over. You point a camera at a square and something happens — a site opens, or a payment app opens with a stranger’s account already filled in. This builds codes, and reads them back so you can see what one says before you let a phone act on it.

  • Encoder written from the specification
  • Reads photos, screenshots and pasted images
  • UPI payment strings taken apart
  • Shorteners and lookalike hosts flagged
  • No decoded link is ever opened

Before you start

This tool runs entirely inside your browser. Nothing you paste or drop here is uploaded, logged or stored — which for security work is the whole point, not a footnote.

What it does not do

  • No uploads — there is no server to upload to
  • No account, no history, nothing saved
  • A decoded link is never opened or resolved
  • No lookups against any external database

Why that matters here

  • Evidence files stay on your machine
  • A token or key you paste is never transmitted
  • Nothing you paste ever appears in your Network tab
  • Works with no internet once the page is cached
  • Free, permanently

Why a QR code is not just a link

        

        

          

            
You cannot hover a square

            
Every piece of advice about checking a link before you click assumes you can see the link. A QR code shows you nothing. The camera app flashes a preview, usually truncated to fit, for about a second — directly above the tap target. That is the entire inspection window most people ever get.

          

          

            
It walks past link scanning

            
Mail gateways and chat filters extract the links in a message and check them. A QR code is a picture: there is no link in the text to extract. That is why quishing lands in organisations that block ordinary phishing links, and why the attachment is so often a PDF or an image with a single square in it. For the message around the square, use the phishing email dissector.

          

          

            
The sticker over the real one

            
The physical attack needs no hacking. Print a code, stick it over the one on the parking meter, the restaurant table, the EV charger or the donation box, and wait. It costs the price of a label. Before you scan a code in public, run a fingernail over the edge and see whether it is a sticker on top of something else.

          

          

            
The payload is an instruction, not a page

            
A code can carry upi:, tel:, otpauth:, a Wi-Fi join or an Android intent. Those are handed straight to an app rather than to a browser you can look inside. The inspector prints the scheme first for exactly that reason.

          

        

      


      

        

          
“Scan this to receive money” is not a thing

          
The single most common QR scam in India, and the one this tool is really for.

        

        

          

            
The direction is fixed by the format

            
A UPI code contains an address to pay. Your app opens with that address filled in, and the PIN you then type authorises money leaving your account. There is no field in the format that pulls money towards you. To be paid, someone scans your code — and your PIN is never involved.

          

          

            
The name in the code is free text

            
The pn field is typed by whoever built the code and is verified by nobody. It can say “SBI Refund Cell”. The only field that decides where the money goes is pa, the address — and the name your app resolves from that address is the one worth reading.

          

          

            
A blank amount is the tell

            
If am is missing, the app asks you to type an amount. That is the version that arrives with a story: enter one rupee to verify, enter the refund amount to claim it. The field is yours to fill in, and filling it in wrongly is the entire scam.

          

          

            
What the defence actually is

            
Read the parsed intent before you approve it. Drop the code into the Inspect half here and it prints the payee, the amount, the note and the handle in plain language, with nothing opened and no app involved. If you are being paid and are asked for a PIN, stop. UPI and payment fraud, taken apart covers the rest of the family: collect requests, mandates and the phone calls that go with them.

          

        

      


      

        

          
How the encoder works

        

        

          

            
Written out rather than pulled in

            
Byte-mode encoding, Reed-Solomon parity over GF(28), mask selection by penalty score, the BCH-protected format block — all of it is in one readable file with the field arithmetic commented. This site carries no dependencies, and a code generator you can read end to end is the only kind whose output you can vouch for.

          

          

            
Error correction is not free

            
Level L recovers about 7% of the code and level H about 30%, and the parity has to fit somewhere: at H the same text needs a bigger, denser grid. H is worth it for something printed and destined to get scuffed. L is worth it when the code has to stay small enough to scan.

          

          

            
The quiet zone is part of the code

            
The specification asks for four blank modules on every side. Scanners use that margin to find the edge, so a code butted straight against dark artwork often will not read. You can set it to zero here to see the effect; it is set to four by default because that is what works.

          

          

            
Print from the SVG

            
SVG stays sharp at any size. A code that has been scaled up from a small bitmap has soft, uneven module edges, and that is the usual reason a printed code refuses to scan when the one on screen was fine.

          

        

      


      

        

          
Questions people ask

        

          

            Does anything here open the link inside a QR code?
            
No. The payload is printed as text and handed to you with a Copy button. There is no automatic navigation, no preview fetch and no redirect following, because requesting a URL tells whoever made the code that someone is looking at it.

          

          

            Can a QR code be used to send me money?
            
No. A UPI QR code names an account to pay, and your PIN authorises money leaving your account. Scanning one can only send. If somebody asks you to scan a code so that you can receive a refund, a prize or a deposit, the money moves the other way and it is a scam.

          

          

            What is quishing?
            
Phishing delivered as a QR code. It works because a picture carries no link for a mail gateway or a chat filter to check, and because you cannot hover a square to see where it goes. The physical version is a printed sticker placed over a real code on a parking meter, a restaurant table or a donation box.

          

          

            Why will it not read my photo?
            
Usually the code is too small in the frame, cut off at an edge, badly blurred, or shot at a steep angle. Fill more of the frame, leave a margin of blank space around the code, and shoot square-on. This reads model 2 QR codes only - Micro QR, Data Matrix, Aztec and PDF417 look similar and are different formats.

          

          

            Is what I type or scan uploaded anywhere?
            
No. The encoder and the decoder both run in this tab and there is no network call in either. A Wi-Fi password you type into the generator, and a payment code you drop into the inspector, stay on your machine.
