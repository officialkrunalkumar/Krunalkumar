Image steganography

Changing the last bit of each colour channel shifts a value by at most 1 out of 255, which no eye can see. That is why a picture can carry a paragraph and look identical — and why hiding one is the fastest way to understand finding one.

  • LSB hide and extract
  • Amplified low-bit view for detection
  • Capacity calculated per image
  • Result downloads as PNG
  • Nothing uploaded

Before you start

This tool runs entirely inside your browser. Nothing you paste or drop here is uploaded, logged or stored — which for security work is the whole point, not a footnote.

Concealment is not protection

        

        

          

            
How LSB works

            
Each pixel has a red, green and blue value from 0 to 255. Replacing the last bit of each changes the colour by at most one step, which is far below what an eye or a screen can resolve. Three bits per pixel means a one-megapixel image carries about 375 KB.

          

          

            
It survives nothing

            
Re-save the image as JPEG, resize it, or upload it anywhere that re-encodes images, and the message is gone — because all of those rewrite exactly the bits it lives in. The result here must stay a PNG.

          

          

            
And it is not encryption

            
Anyone who suspects LSB reads it with the Extract button on this page. There is no key. Steganography hides the existence of a message; cryptography protects its contents. If the content matters, encrypt it before hiding it.

          

          

            
Finding hidden data

            
The low-bit view amplifies every least-significant bit to full brightness. Real image noise looks like static. Visible text, sharp edges, or a solid rectangle of noise in one corner means something was written there — which is exactly how this is detected in practice.

          

        

      


      

        

          
Questions people ask

        

          

            What is steganography?
            
Hiding the existence of a message rather than its contents. Encryption makes a message unreadable; steganography makes it unnoticed. They solve different problems and are strongest used together.

          

          

            Why must the output be a PNG?
            
PNG is lossless, so the exact bit values survive. JPEG is lossy and recalculates pixel values during compression, which destroys the hidden data completely.

          

          

            Can this extract messages hidden by other tools?
            
Only if they use the same scheme - last bit of each RGB channel, in order, with a 32-bit length header. Bit order and channel order vary between implementations. The low-bit view still helps you see whether anything is there.

          

          

            Is the image uploaded?
            
No. The pixels are read and rewritten in your browser, and the result comes back as a download.

          

          

            How much can I hide in one image?
            
Roughly three bits per pixel, so about 375 KB per megapixel. The exact capacity for your image is shown when you load it.
